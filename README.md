# birdie-models

Model files downloaded by the Birdie app on first use. Files are attached to GitHub
Releases, not committed. Each release tag is one pack version (`sound-id-v1`, …).

| File | What | Licence |
|---|---|---|
| `perch_v2_int8.tflite` | Google Perch 2.0 (`perch_v2_cpu`), TFLite int8 | Apache-2.0, see `LICENSE` and `NOTICE` |
| `sound_labels.json` | bird classes, names, country prior | CC0 / CC BY 4.0 data, see `NOTICE` |
